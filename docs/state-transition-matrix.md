# State-transition matrix

| State/record                         | Required prior basis                                            | Positive decision forced? |
| ------------------------------------ | --------------------------------------------------------------- | ------------------------- |
| Submitted                            | Outcome, OEN, boundary, exact external package                  | No                        |
| Under review                         | Valid submission and Auditor assignment                         | No                        |
| Evaluated                            | Assessment(s), evidence basis, human Auditor act                | No                        |
| Determined                           | Separate evaluation, declared residual risk, human Director act | No                        |
| Authorized / conditional             | Supporting determination, accepted risk, same Director          | No                        |
| Withheld/deferred/not authorized     | Director decision basis                                         | No                        |
| Expired/withdrawn/revoked/superseded | Preserved prior authorization plus change record                | No                        |
| Reassessment required                | Changed evidence/boundary/basis                                 | No                        |
