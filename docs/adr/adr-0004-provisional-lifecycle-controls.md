# ADR-0004: Provisional lifecycle integrity controls

- Status: Provisional; ICxA governance approval required

Expiry, withdrawal, revocation, supersession, reassessment, canonicalization, namespace, and technical conformance labels are necessary exchange-integrity decisions not fully named by ICXA-10001. They are explicit draft protocol controls and are not claimed as verbatim ICxA requirements. Governance must approve or revise them before an official release.
