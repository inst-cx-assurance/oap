# ADR-0001: Independent Level 1 protocol

- Status: Accepted for draft
- Date: 2026-09-02

OAP is a separate Level 1 protocol and repository. It neither extends nor modifies OCRS. Software records and validates supplied human acts but receives no Auditor, Director, risk-acceptance, or authorization authority. This implements ICXA-10001 clauses 5.3, 8.2, and 8.3.
