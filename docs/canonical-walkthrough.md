# Canonical Alpha walkthrough

Scenario A binds the OCRS CW-101 RFDC package as Level 2 evidence. Its metadata matches the real OCRS v0.1 ready fixture, while `claimedValidationStatus` remains only an assertion. A delivery role submits it; an independent fictional human Auditor records sufficiency; a different fictional human Director records a determination, accepts declared residual risk, and explicitly authorizes only the stated boundary and validity period.

Scenario B changes the assessment to insufficient/stale; the human records then state non-support, non-acceptance, and withholding. Scenario C demonstrates structured conditional authorization; its detailed condition fields remain provisional pending approval of the reviewed ICXA-20101 material. Scenario D preserves the original authorization basis when the OCRS package changes and records a human reassessment requirement. Scenario E is intentionally invalid for authority conflict.

Additional valid conformance scenarios cover a complete two-criterion assessment, a narrower non-expanding Director delegation, a timely mitigated conflict declaration, deterministic expiry after `validTo`, authorized withdrawal, and authorized revocation. Withdrawal and revocation preserve the current historical record version while deterministic classification makes it ineffective. These scenarios demonstrate core representability and integrity rules, not ICxA Profile Conformance.
