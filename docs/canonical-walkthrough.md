# Canonical Alpha walkthrough

Scenario A binds the OCRS CW-101 RFDC package as Level 2 evidence. A delivery role submits it; an independent fictional human Auditor records sufficiency; a different fictional human Director records a determination, accepts declared residual risk, and explicitly authorizes only the stated boundary and validity period.

Scenario B changes the assessment to insufficient/stale; the human records then state non-support and withholding. Scenario C demonstrates structured conditional authorization, as permitted by the source requirement to record conditions and limitations. Scenario D preserves the original authorization basis when the OCRS package changes and adds a reassessment trigger. Authority-conflict cases are intentionally invalid.
