# Gate and interface coverage matrix

| Interface                                         | OAP representation                 | Authority effect                               |
| ------------------------------------------------- | ---------------------------------- | ---------------------------------------------- |
| OCRS RFDC                                         | Exact external package reference   | Evidence only                                  |
| OCRS ORC/AOCR/IOC/FOC                             | Generic external package reference | Evidence only; no detailed OAP mapping claimed |
| Readiness Review/Recommendation/decision          | External evidence inventory/basis  | Never authorization                            |
| System Handover / Transfer of Operational Control | External subject/boundary evidence | Never authorization                            |
| Level 1 Outcome Authorization                     | Explicit human OAP record          | Only within supplied governance and authority  |
