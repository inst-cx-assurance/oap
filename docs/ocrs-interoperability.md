# OCRS-to-OAP interoperability

OAP consumes only an integrity-bound external reference containing OCRS protocol/profile versions, package/manifest identity, canonical content hash, inventory digest, project, subjects, boundaries, producer, custody, qualifications, exclusions, validation and supersession. OAP does not copy OCRS records as authoritative OAP records and OCRS requires no OAP code.

Any OCRS `satisfied` result, Review, Recommendation, readiness decision, Handover or Transfer of Operational Control is evidence input only. A changed OCRS digest, version or inventory requires a new submission or controlled reassessment.
