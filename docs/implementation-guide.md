# Implementation guide

Parse with resource limits, meta-validate all schemas, compile the package union, reject structural failures, index unique IDs, validate exact inventory and typed references, and verify canonical digests. Then apply the language-neutral semantic rules in the normative specification: exact context equality; OEN sequence; criterion and assessment coverage; evidence-package subsets; complete evaluation and decision bases; one decision chain; risk-owner and risk-context integrity; role, time, scope, delegation, conflict and separation controls; condition backlinks and closure; lifecycle authority; profile agreement; and complete supersession graphs.

Return every independently detectable failure with its stable diagnostic code, path, message, and supporting IDs. TypeScript is not the normative source. Implementations in other languages must reproduce the specification, vectors, fixtures, and diagnostics.

Core validation does not fetch external evidence. Full OCRS verification accepts explicit local content and compares every binding supported by the OCRS v0.1 adapter. It never creates a human evaluation, determination, risk acceptance, authorization, withdrawal, or revocation record.
