# OAP v0.1 build brief

Build a private draft of a separate Level 1 Outcome Assurance Protocol from ICXA-10000:2026 Rev 0, ICXA-10001:2026 Rev 0, and ICXA-10002:2026 Rev 0. Treat ICXA-10003 as informative. Preserve a one-way, integrity-bound interface to Level 2 packages including OCRS; never import Level 2 authority or infer authorization.

The draft must keep evidence production, independent evidence evaluation, Outcome Director judgment, residual-risk acceptance, and Outcome Authorization distinguishable and auditable. Software validates supplied records but performs none of those human functions. Exact ICxA profile approval, licensing, namespace, governance appointments, public release, certification, and signing/trust policy remain open.
